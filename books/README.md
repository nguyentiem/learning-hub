# Books

Book notes, reading lists, summaries in your own words, and reading progress.

## Add a book

Create a folder using `author-title` or `title`, then add a `README.md` based on [`../templates/NOTE_TEMPLATE.md`](../templates/NOTE_TEMPLATE.md). Track the title, author, source, status, and key takeaways. Link to the publisher or library rather than storing copyrighted book content.
