## Add a course

Create a folder using a short kebab-case name, then add a `README.md` based on [`../templates/NOTE_TEMPLATE.md`](../templates/NOTE_TEMPLATE.md). Include the provider, course URL, topics, exercises, and status. Keep notes original and link to the course materials.
