# Templates

This directory contains reusable templates for notes, projects, and learning artifacts in the Learning Hub.

## Available templates

- [`NOTE_TEMPLATE.md`](./NOTE_TEMPLATE.md) — for books, courses, references, or study notes
- [`PROJECT_TEMPLATE.md`](./PROJECT_TEMPLATE.md) — for engineering projects and experiments

## Recommended usage

- Use `NOTE_TEMPLATE.md` for any subject-based note, summary, or resource index.
- Use `PROJECT_TEMPLATE.md` for personal builds, experiments, and prototypes.
- Keep files descriptive and aligned with the folder structure in the repo root.

## Typical workflow

1. Pick the relevant template.
2. Copy it into the correct topic folder.
3. Replace the placeholder fields with your content.
4. Add a short summary or link back to the source material.
5. Update the parent README to keep the repo navigable.

## Naming convention

Prefer lowercase, kebab-case names for folders and files, for example:

- `books/designing-data-intensive-applications/README.md`
- `projects/secure-boot-manager/README.md`
- `roadmaps/rust-learning-roadmap.md`

## Rule of thumb

Store your own summary and original notes here. For external sources, cite the link and keep the central idea in your own words instead of copying large portions of text.
