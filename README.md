# Learning Hub

A central index for Nguyen Tiem's books, course notes, learning roadmaps, and engineering projects.

> Keep this repository as an index and learning workspace: organize material by type, link to original sources, and record progress in a consistent format.

## Repository map

| Area | Purpose |
| --- | --- |
| [`books/`](books/README.md) | Book notes, summaries, and reading progress |
| [`courses/`](courses/README.md) | Course notes, exercises, and completion status |
| [`roadmaps/`](roadmaps/README.md) | Learning plans, milestones, and skill checklists |
| [`projects/`](projects/README.md) | Engineering projects and build logs |
| [`resources/`](resources/README.md) | Useful references, tools, and curated links |
| [`templates/`](templates/) | Reusable formats for notes and project plans |

## How to use this repository

1. Choose the matching area and add a folder or Markdown file for the subject.
2. Start from a template in [`templates/`](templates/) where applicable.
3. Include the source URL and date for external material; distinguish your own notes from quoted content.
4. Update the relevant area README so this repository remains easy to navigate.
5. Use descriptive names, for example `books/designing-data-intensive-applications/` or `courses/typescript-fundamentals/`.

## Suggested conventions

- Use Markdown for notes and indexes.
- Keep one subject per folder; use lowercase kebab-case names.
- Record progress with simple statuses: `Not started`, `In progress`, or `Completed`.
- Avoid committing credentials, private data, or copyrighted course/book content. Store your own summaries and link to the original source instead.

## Language

Notes may be written in Vietnamese or English. Keep each document consistent and mention the language in its metadata when useful.
